# Raytracer

This ray tracer is a high-performance rendering engine developed, specifically engineered to support advanced visual effects through non-recursive and recursive ray tracing. It implements many features including texture and bump mapping, accurate refraction and reflection via Snell’s law, and shadow computation. To optimize for high-fidelity animations, the engine utilizes max thread parallelization, adaptive supersampling to balance image quality with render time, and a custom cubic-spline interpolation system for fluid camera and object animation.
